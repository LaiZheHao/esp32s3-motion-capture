# ESP32-S3 单板航向漂移排查与处理

日期 2026-11-14。适用硬件为 ESP32-S3、ICM-42688-P 六轴 IMU 和 LIS2MDL 磁力计，分析对象为 8000 开发台的单板姿态。已知测试板物理 ID 为 `imu_305A6077C398`，基线提交为 `caa9431`。实际复测前请核对设备、固件和生效的处理策略。

这份记录交给负责姿态融合的队友。建议先用陀螺零偏补偿和六轴融合建立可重复的静止基线，再验证标定后的磁场能否提供可靠航向参考。位移测量由另一条测试线继续，其六面标定、起止窗和误差验收独立记录。

## 2. 发生原理

板子静止时，加速度计量到约 1 g 的比力，方向可以用来确定实验中的竖直方向，从而约束倾斜。沿竖直方向旋转时，重力相对板子的分量保持不变，所以重力无法告诉程序水平朝向转了多少。若板子侧立 `+X` 朝上，实验竖直方向主要对应板卡 X 轴。此时判断航向漂移要看沿重力方向投影的陀螺读数，不能固定只看板卡 Z 轴。

陀螺仪量角速度。物理上静止时，测到的角速度仍可能包含零偏、噪声和随温度变动的残差。若竖直方向还剩 0.05 °/s 的近似恒定零偏，单靠积分推算航向，1 分钟就可能积出约 3°。加速度计六面标定修正的是三轴加速度的零偏和比例。陀螺仪静置校准估计的是零转速时的偏置。两项都能改善测量，但零偏补偿之后，六轴融合仍缺少独立的长期航向观测。

磁力计可以用局部磁场的水平分量提供航向参考。板卡、电池、支架、电脑和附近金属或磁铁可能令磁场偏移或变形。硬铁误差表现为场向量整体偏移，软铁误差表现为各方向尺度和方向的变形。三维磁标定能补偿随设备固定、可重复的一部分干扰。场地磁干扰和工作状态变化仍要靠质量门控处理。磁参考用于约束相对起始方向或共同参考方向，局部磁环境需要通过独立的角度测试确认。

静止保持有第三种用途。程序认定板卡停稳后可冻结显示姿态，适合减少静止时的视觉漂移。极慢真转动也可能被误判为静止，因此静止保持单独验收，评估融合漂移时先关闭。

## 3. 建议做法

使用**静置陀螺零偏补偿 + 六轴倾斜校正 + 合格磁场才参与航向**。先验证已有路径，再决定需不需要修改融合算法。

1. **确保零偏可靠。** 固定板卡后上电，保持实际 Wi-Fi 供电和安装方式。选中设备，在「标定 → 静置校准」做陀螺零偏校准。校准会先等待约 0.8 s，再至少采 4 s 和 200 个有效样本。读到通过状态后记录三轴零偏、温度、采样数和质量。对更换设备、重启或重置参考的试次，记录事件并重新核对零偏及参考。
2. **建立六轴对照。** 在「高级 → 融合策略与停稳保持」选 `six_axis_relative`，关闭「校准后停稳保持」，记录静止段和已知角度动作。页面改变处理策略会撤销安装参考，涉及人体显示时按实际佩戴重新初始化。比较时用同样的起始朝向和测量窗口。
3. **先检查磁环境，再拟合。** 把手机磁吸附件、扬声器、充电仓等移远，用木质或塑料支架。保持装配和供电状态不变，选一个磁环境稳定的位置，固定中心位置附近缓慢转动板卡，覆盖各种倾角与方位。只转一圈水平角或只摆六个面，可能达不到三维拟合所需的方向覆盖。采集一个启动会话内至少 300 个有效三维磁场样本。当前工具会检查场强、方向覆盖和残差。
4. **对合格候选做磁参考对照。** 通过现有 `set_magnetic_calibration` 操作把合格候选应用到对应物理 ID，再用 `magnetic_guarded` 在相同工况复测。它会检查磁力计有效位、场强和水平分量质量，异常时回到六轴。磁场参与标记高也可能伴随偏差，必须比较角度真值和低速转动表现。磁环境不合格时可先用六轴做短时相对姿态，记清没有长期绝对航向参考。

在仓库根目录运行磁标定候选工具。请把占位会话替换成新录的磁场采集会话，并为候选文件选一个可写的本地位置。

```powershell
.\host\.venv\Scripts\python.exe .\tools\fit_magnetometer.py "host/recordings/磁场采集会话ID" --device imu_305A6077C398 --output "magnetic-candidate.json"
```

输出 JSON 是该设备的候选参数。命令报错时先按错误排查采集，原有运行配置可以保留。已有 `host/config/magnetometer_v1.json` 的仓库默认 `devices` 为空，运行机器上的配置和设备生效状态以实际检查为准。当前设备的仓库默认处理策略是 `magnetic_guarded`，已有旧文档也记过该板曾使用六轴。复测以页面与录制中的实际策略为准。

## 4. 复现与排查顺序

### A. 先确认采样和显示

- 用 Wi-Fi TCP 接一块板，记录设备 ID、`boot_id`、`sequence`、`device_us`、六轴和磁场有效标记、固件、处理策略、停稳保持状态和温度。确认录制中没有重启和序号缺口。若有重启或明显的采样时间异常，记录发生时刻，再补采连续段用于对照。
- 取保存的 `fused_quaternion` 或同一节点状态的融合四元数，与「板卡姿态」显示对照。接近竖直放置时，ZYX 欧拉角可能在 ±180° 处回绕，或在俯仰接近 ±90° 时出现分量跳变。计算时用四元数，或把一个可用的板卡方向投影到实验水平面并展开角度。投影很短时换另一根不近竖直的板卡轴，同一次对照全程使用同一根轴。
- 若融合四元数基本不变，但画面或角度读数在转，检查显示插值、坐标映射、参考重置和欧拉角转换，再进入传感器试验。

### B. 做静止、回转和慢转对照

| 试次 | 操作 | 要记录的结果 |
| --- | --- | --- |
| B1 六轴静置 | 板子固定，校准零偏后关闭停稳保持。平放连续观察 60 s。在设备时间连续的记录里，分别报告前 10 s 和全段。再以固定的 `+X` 朝上复测一轮 | 经零偏补偿后，陀螺在竖直方向的均值与波动、航向末值变化和最大偏离、倾斜变化、温度 |
| B2 磁参考静置 | 合格磁标定后，沿用 B1 的位置、姿态、供电、测量时长和关闭保持设置，切为 `magnetic_guarded` | 与 B1 同一指标。另记磁场实际参与比例、回退原因和是否出现跳变。记下切换和收敛时刻，分别报告收敛阶段与固定窗口结果 |
| B3 磁参考动态 | 用纸质角度盘和无磁固定底座，绕实验竖直方向做 0° → +90° → 0°，再做反向。重复 3 次。再做一次慢转（例如 10 s 转 10°） | +90° 的误差、回零误差和慢转是否跟随。若测保持功能，在关闭与开启保持下做同一慢转 |
| B4 磁场干扰复查 | 板不动，在原工位重现异常磁场。对比移开可疑物前后。板姿态、供电和策略保持一致 | 原始及校正磁场模长、水平场、实际磁场参与标记及角度是否突跳。尽量每次只改变一个条件 |

60 秒记录可用于航向诊断，从 `samples.jsonl` 读取即可。位移解算器有自己的动作时长和样本数要求，航向诊断不需要走位移导出。

### C. 根据结果定位

| 复测发现 | 下一步 |
| --- | --- |
| 固定时原始陀螺异常偏大、出现尖峰或零偏随温度显著变化 | 复核原始轴、单位 °/s、固件版本、上电时是否固定、供电、安装应力和振动。若正常预热并重新校准后仍重复出现，可用同设置的另一块板作对照。历史 r4 曾发生启动偏差异常，r5 已去除库启动阶段留下的三轴偏置，复测要确认实际运行版本 |
| 六轴航向缓慢变化，变化量和残余竖直角速度相符 | 优先复核陀螺零偏估计和温度影响。需要更长时间的方向稳定时，使用通过独立验证的磁参考或其他可观测的航向参考 |
| 开启磁参考后漂得更快或出现跳变 | 对照磁场回退与角度异常时刻，先查磁环境、安装件和三维标定。若环境和标定反复通过、切换时仍出现跳变，再改融合，重点考虑磁航向观测拒绝、恢复时逐步引入和只校正航向 |
| 只有开启停稳保持才变得稳定 | 将其记录为保持功能的表现。用独立角度和慢转试验检查是否误抑制动作 |
| 姿态基本只在重启、丢帧或切换参考时突变 | 先按 `boot_id`、`sequence` 和事件定位设备重启、断流或参考重置，按完整连续区间重算漂移 |
| 只有侧立时欧拉角大跳，水平投影或四元数连续 | 检查欧拉角奇异点和角度回绕，使用绕实验竖直方向的指标比较航向 |
