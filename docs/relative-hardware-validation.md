# 双节点周期相对位置约束：实板验证窗口

启动现有开发台后打开 <http://127.0.0.1:8000/static/relative_validation.html>。该窗口读取完整已保存记录，不通过低频网页状态快照冒充完整原始采样，不修改传感器融合、Wi-Fi 或固件，也不会主动连接、停止连接或启动录制。

## 实板流程

1. 在原有开发台连接两块板，同时录制并停止保存。推荐先录 10～20 秒，保持节点 ID 不变、供电稳定。连接方式沿用已有功能。本窗口无法使一块 Wi-Fi 网卡同时连接两个不同热点；使用现有支持的双节点采集方式，或 USB 与 Wi-Fi 组合。
2. 保证起点相对位置 `B − A` 已知，起点相对速度已知；初速度填零仅适用于起点两板相对静止。之后周期归位时无需停稳。板卡姿态融合已经完成必要校准，两节点的竖直方向和航向必须处于同一参考系。
3. 外部记录各次实际回到已知相对位置的时间和三维相对向量。周期节拍只是操作提示，不代表准确的实际归位时刻。位置是有符号的 XYZ 向量，只有距离已知无法直接使用本模型。
4. 在新窗口刷新会话并选择刚保存的记录，或上传从开发台导出的 ZIP / `samples.jsonl`。选择节点 A、B。起点是两个节点对齐采样时间区间的共同起点，事件时间从该点计秒。
5. 填写每个融合坐标到共同坐标的航向角，以及起点相对位置、速度。航向角按右手系绕 Z 旋转，正角使 X 转向 Y；默认 0° 不证明坐标已经对齐。此版本假定融合输出的竖直轴正确，仅提供额外航向旋转，不会自动做两板外参标定。记录中的时间是现有软件近似对齐结果，并非硬件同步保证；应评估同步和网络延迟影响。
6. 在事件框逐行填写 `时间秒,相对X米,相对Y米,相对Z米`。可手动添加单个时刻，或每两秒生成草稿后按实际外部记录修改。确认真实归位事件及共同坐标后运行。
7. 对比无约束、仅重置相对位置、位置观测＋速度／零偏估计三种方案。观察各分量轨迹和校正前残差，导出 JSON 与 CSV 保存分析结果。修改参数后旧结果自动失效，需要重算。

## 数据契约和分析边界

输入复用现有 `samples.jsonl` 的逐行 `{time_s,data}`。每条 data 包含 `source="real"`、`device_id`、`raw.sequence`、`raw.boot_id`、有效的 `raw.sensor_flags`、`aligned_monotonic`、`mapped.accel`（g）和 `quaternion`（wxyz）。工具把映射后加速度用该四元数转到融合坐标，再扣除 +Z 方向的重力，并应用用户设置的航向旋转。不会用骨架安装四元数旋转原始加速度，也不重跑姿态融合。

同一节点必须单次启动、序号连续、对齐时间严格递增，相邻帧不得超过 80 ms；不足两个实板节点、混合模拟来源、重启或缺帧拒绝分析。上传文件限 128 MiB、解析限 20 万条、共同分析时长限 1～180 秒。两个节点按共同对齐时轴线性插值至不大于 10 ms 的积分步长，事件在填写的精确时刻施加；这不能恢复丢失样本或修复原始同步误差。

分析状态为逐轴的相对位置、速度、加速度零偏；位置测量只在事件时刻生效，不清零速度。噪声初值沿用合成仿真，尚未进行实板参数辨识；位置观测 σ 可调。起点状态的不确定度也沿用仿真，起点不准确会影响收敛。本窗口没有对共同绝对位置进行估计或验证。

“校正前约束残差 RMS”是估计位置与输入约束位置在校正前的三维差值模长的 RMS；约束已经是算法输入，残差不是独立的精度测量。若要证明厘米级精度，应另外保留未参与校正的尺量位置或外部定位轨迹作为验证集。CSV 保存更新后轨迹；JSON 同时保存配置、事件及校正前残差，以便追溯。

该页面是离线实板数据验证入口，不是已完成双板硬件验收。本次仅完成数学模块自动测试、页面空数据保护与会话目录读取验证，未实际移动两板采集。

## 开发与扩展入口

- `host/web/relative_validation_math.js`：纯计算模块，`parseSamples(text)` 读取现有记录；`compare(groups, config)` 接收归位事件 `fixes:[{time,position:[x,y,z]}]`。后续可以让外部触发器产生该事件列表，仍保留真实事件时间，避免用定时器代替实际位置观测。
- `host/web/relative_validation.html` 和 `relative_validation.js`：独立窗口、会话选择、本地导入、事件编辑和结果导出。
- 测试：在 host 目录运行 `node tests/test_relative_validation.js`。覆盖运动中校正保留非零速度、固定偏差估计、约束间隔误差改善及无效记录拒绝。
